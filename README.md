# Draconis · Soporte Académico

Sitio web comercial estático, responsive y modular para Draconis.

## Incluye

- Portada medieval/mágica con identidad morado + fuego.
- Menú lateral desde las tres líneas superiores izquierdas.
- Sección Sobre nosotros.
- Servicios y niveles académicos.
- Casas del conocimiento con tarjetas clicables a WhatsApp.
- La Orden Draconis, Equipo Erudito y Maestres.
- Contadores de experiencia/resultados.
- Carrusel de testimonios preparado para capturas reales.
- Sección de videos YouTube/TikTok.
- Buzón de cotización responsive.
- Guardado opcional en Supabase + apertura obligatoria de WhatsApp.
- Sección Únete a la Orden con WhatsApp prellenado.
- Botón flotante con el dragón y distintivo de WhatsApp.

## Configuración rápida

Lee `CONFIGURAR_AQUI.txt`. La idea es que no tengas que buscar datos dentro de los archivos grandes.

## Nota

Los servicios académicos deben comunicarse y prestarse de acuerdo con las reglas de cada institución. El sitio usa lenguaje de tutoría, acompañamiento, revisión y apoyo académico.
